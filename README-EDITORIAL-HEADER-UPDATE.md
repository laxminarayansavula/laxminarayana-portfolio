# Editorial header consistency update

Updated homepage headers for Selected Work, About, and Approach to use a consistent editorial composition: section label, large left-aligned headline (up to 88px), cyan highlight, and supporting copy on the right. Approach keeps its six-stage process as a separate, smaller horizontal sequence below the header. Mobile collapses each header to one column. Changes are scoped to the homepage and retain reduced-motion support.

Please verify the page at desktop and mobile widths and run a WCAG contrast check before deployment.
